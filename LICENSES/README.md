# Third-party license texts

These are copies of license and notice files from the installed runtime packages used for the Windows build and the official Qt 6.12.0 source archives listed in `../docs/qt-source-manifest.md`.

- `Qt/<source-archive-name>/LICENSES/` preserves each archive's module-level license files, including repeated files where they came from distinct modules.
- `Python/<package-version>/` preserves the license and notice files supplied by that installed package.
- `Lucide-ISC.txt` contains the ISC notice for the bundled Lucide SVG asset.

The presence of a license text does not select a license option for a component, resolve which license applies to each binary, or establish compliance. See `../docs/LICENCIAMENTO_QT.md` and `../THIRD_PARTY_NOTICES.md`.
